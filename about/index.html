About Which Ink Fits

Which Ink Fits answers two questions. Which cartridge, toner, or bottle fits this printer, and which printers does this number fit?

What we cover

HP, Canon, Epson, and Brother, using each company's own compatibility pages. We add a model when that page names it. We leave it out when the page does not.

Independence

Which Ink Fits is not affiliated with, endorsed by, or sponsored by HP, Canon, Epson, or Brother. Names are used only to identify the printers and supplies.

See sources and methods. To report a wrong number, write to us.

Which Ink Fits lists the ink, toner, and bottle numbers the printer maker publishes for a model, and the printers a number fits. Independent, and not affiliated with HP, Canon, Epson, or Brother. Confirm the number on the maker's page and on your printer.
